# 🏎️ AutoX | High-Performance Luxury Automotive Portal

![AutoX Banner](https://images.unsplash.com/photo-1614162692292-7ac56d7f7f1e?q=80&w=2070&auto=format&fit=crop)

AutoX is a cutting-edge web experience designed for the next generation of luxury automotive enthusiasts. Built with a focus on **60FPS fluidity**, 3D parallax interactions, and a bespoke smooth-scrolling architecture.



---

## ⚡ Key Features

* **Elite Performance:** Optimized with GSAP `quickSetter` and CSS GPU acceleration (`translateZ(0)`) for lag-free rendering.
* **Immersive 3D Tilt:** Adaptive card system with parallax depth, follow-me shine effects, and `preserve-3d` transformations.
* **Lenis Smooth Scroll:** A fully integrated smooth-scrolling engine synced with GSAP animations for a cinematic browsing feel.
* **X-Series Collection:** A horizontally scrolling showcase utilizing `IntersectionObserver` for efficient state management and performance.
* **Responsive Architecture:** Meticulously crafted for seamless experiences across mobile, tablet, and ultra-wide desktop displays.
